# ChatGPT Quota Monitor

[English](./README.en.md) | 简体中文

一个轻量、无运行时依赖的 **Tampermonkey 用户脚本**，在普通 ChatGPT 网页左侧栏账号入口上方增加一个**额度图标按钮**，点击才弹出桌面版风格的套餐用量卡片。进入 **Work 会话**时，保留右上角「输出 / 来源」面板额度区，不会重复显示。

> **免责声明：** 本项目是非官方社区工具，不隶属于 OpenAI。数据来自 ChatGPT 内部接口，接口非公开且不保证稳定。以 ChatGPT **设置 → 用量（Settings → Usage）** 中的数据为准。

## 功能

- **5 小时 / 每周额度**：根据实际窗口长度识别，不固定假设 primary / secondary 的位置。
- **真实剩余比例**：基于接口返回的已用百分比，绝不通过消息数量估算。
- **重置倒计时**：每秒本地更新，不会每秒向服务器发送请求。
- **自动刷新**：页面可见时每约 60 秒刷新，并支持手动刷新。
- **点击才显示**：普通聊天左侧栏仅增加一个 34px 的额度按钮，默认不展示卡片；点击打开，再次点击或点击面板外、按 Esc 均可关闭。
- **桌面版风格弹窗**：展示套餐来源、5 小时/周剩余比例、额外额度以及「管理用量」链接。弹窗会自动在视口内定位，不挤占侧栏内容。
- **Work 右上角额度区**：保持原有的「输出 / 来源」卡片集成、进度条、倒计时和折叠功能。
- **自动布局切换**：Work 侧栏存在时优先显示右侧，普通聊天使用左侧；一次只显示一个额度组件。展开侧栏时才显示，窄图标栏和移动窄窗口不显示。
- **错误处理**：登录过期、请求超时、接口缺失时明确提示；未返回的额度不会显示虚构数值。
- **自动更新**：Tampermonkey 可从 GitHub main 分支检查更新。

## 安装

1. 安装 [Tampermonkey](https://www.tampermonkey.net/) 扩展，并允许在 ChatGPT 运行用户脚本。
2. [**点击安装脚本**](https://raw.githubusercontent.com/MillioApaski/ChatGPT-Quota-Monitor/main/chatgpt-quota-monitor.user.js)。
3. 打开或刷新 https://chatgpt.com/ 的**普通聊天**，展开左侧栏，在账户头像入口上方找到小型额度按钮。
4. 点击按钮弹出套餐用量卡片；再次点击、点击空白处或按 **Esc** 关闭。**Work 会话**继续在右上角「输出 / 来源」卡片中显示额度区。

## 数据与隐私

脚本只请求 chatgpt.com 上的两个同源接口：

- `/api/auth/session`：取得当前登录会话的临时访问令牌，令牌仅在运行内存中使用，不保存。
- `/backend-api/wham/usage`：取得用量窗口、已使用比例、重置时间及可选的 `credits` 余额。

没有第三方请求、遥测或外部依赖。localStorage 只保存 Work 额度区的折叠状态。

**注意**：这里显示的是 **Work / Codex 共享套餐用量**，并不代表普通聊天消息条数或各模型单独的额度。不同套餐窗口不同。左侧「额度」读取可选字段 `credits.balance`，只有服务端明确返回数值、无限额度或 `has_credits: false` 才显示对应结果；否则显示「未提供」，绝不猜成 0。

## 排错

- **接口未提供**：账户可能没有该窗口，或接口字段改变。请查看官方 Settings → Usage。
- **HTTP 401 / 403**：会话可能失效，或接口对该账户不可用。请重新登录并刷新。
- **面板未出现**：确认 Tampermonkey 已启用；普通聊天需要**展开左侧栏**，Work 需要「输出 / 来源」（或 Output / Sources）右上角面板。侧栏折叠或窄屏时不会强行覆盖内容。
- **数据不一致**：脚本周期性读取内部接口，官方用量页面的数据优先。

提交 Issue 时只能提供**脱敏的字段结构**，不要泄露 Token、Cookie、邮箱或账号信息。

## 开发

Node.js 20+；无第三方依赖：

```bash
npm test
```

CI 将检查脚本语法、额度解析测试及 Tampermonkey 更新元数据。发布时同步修改脚本 `@version` 和 package.json 中的版本，推送 `vX.Y.Z` 标签可自动创建 Release。Tampermonkey 从 main 分支获取更新。

## 兼容性说明

脚本优先通过 Work 「输出 / 来源」标题及位置识别右上角面板；普通聊天通过展开侧栏的账户按钮（`accounts-profile-button`）挂载图标，必要时使用侧栏 footer 备用定位。弹窗只有点击时才会创建并附加到页面顶层，以避免侧栏裁剪；关闭后立即移除。两者都不是公开稳定的 DOM API，OpenAI 改版时可能需要更新定位规则。**当前修改需要在实际网页登录环境确认外观和定位。**

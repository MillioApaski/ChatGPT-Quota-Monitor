# ChatGPT Quota Monitor

[English](./README.en.md) | 简体中文

一个轻量、无运行时依赖的 **Tampermonkey 用户脚本**，在普通 ChatGPT 网页左侧栏账号入口上方增加一个**与原生侧栏对齐的「额度」菜单行**，包含桌面版风格的动态额度圆环图标。点击后弹出套餐用量卡片。进入 **Work 会话**时，保留右上角「输出 / 来源」面板额度区，不会重复显示。

> **免责声明：** 本项目是非官方社区工具，不隶属于 OpenAI。数据来自 ChatGPT 内部接口，接口非公开且不保证稳定。以 ChatGPT **设置 → 用量（Settings → Usage）** 中的数据为准。

## 功能

- **5 小时 / 每周额度**：根据实际窗口长度识别，不固定假设 primary / secondary 的位置。
- **真实剩余比例**：基于接口返回的已用百分比，绝不通过消息数量估算。
- **重置倒计时**：每秒本地更新，不会每秒向服务器发送请求。
- **自动刷新**：页面可见时每约 60 秒刷新，并支持手动刷新。
- **桌面版真圆弧额度图标**：上方短弧表示 5 小时剩余比例，下方长弧表示每周剩余比例；两段均为同圆心同半径的 SVG 圆弧，并统一从左向右显示进度。亮色表示剩余部分，橙色短段表示已用部分（例如剩余 92% 对应已用 8%，剩余 99% 对应已用 1%），即使消耗很少也更容易分辨。没有 5 小时窗口时，周额度改为完整圆环。
- **对齐原生侧栏**：普通聊天左侧栏增加 44px 高「额度」菜单行，动态测量账户头像中心与用户名文字的起点，分别使用定位坐标对齐图标与文字，不再依赖 flex 间距；同时缩小图标，匹配原生头像大小。点击打开弹窗，再次点击、点击面板外或按 Esc 关闭。
- **桌面版风格弹窗**：展示套餐来源、5 小时/周剩余比例、额外额度以及「管理用量」链接。弹窗优先显示在整个侧栏的右侧，并在视口边缘自动调整，不压住账户菜单，也不挤占侧栏内容。
- **Work 右上角额度区**：保持原有的「输出 / 来源」卡片集成、进度条、倒计时和折叠功能。
- **自动布局切换**：Work 侧栏存在时优先显示右侧，普通聊天使用左侧；一次只显示一个额度组件。展开侧栏时才显示，窄图标栏和移动窄窗口不显示。
- **错误处理**：登录过期、请求超时、接口缺失时明确提示；未返回的额度不会显示虚构数值。
- **自动更新**：Tampermonkey 可从 GitHub main 分支检查更新。

## 安装

1. 安装 [Tampermonkey](https://www.tampermonkey.net/) 扩展，并允许在 ChatGPT 运行用户脚本。
2. [**点击安装脚本**](https://raw.githubusercontent.com/MillioApaski/ChatGPT-Quota-Monitor/main/chatgpt-quota-monitor.user.js)。
3. 打开或刷新 https://chatgpt.com/ 的**普通聊天**，展开左侧栏，在账户头像入口上方找到带动态圆环图标的「额度」菜单行。
4. 点击按钮弹出套餐用量卡片；再次点击、点击空白处或按 **Esc** 关闭。**Work 会话**继续在右上角「输出 / 来源」卡片中显示额度区。

## 数据与隐私

脚本只请求 chatgpt.com 上的两个同源接口：

- `/api/auth/session`：取得当前登录会话的临时访问令牌，令牌仅在运行内存中使用，不保存。
- `/backend-api/wham/usage`：取得用量窗口、已使用比例、重置时间及可选的 `credits` 余额。

没有第三方请求、遥测或外部依赖。localStorage 只保存 Work 额度区的折叠状态。

**注意**：这里显示的是 **Work / Codex 共享套餐用量**，并不代表普通聊天消息条数或各模型单独的额度。不同套餐窗口不同。左侧「额度」读取可选字段 `credits.balance`，只有服务端明确返回数值、无限额度或 `has_credits: false` 才显示对应结果；否则显示「未提供」，绝不猜成 0。

## 排错

- **接口未提供**：账户可能没有该窗口，或接口字段改变。请查看官方 Settings → Usage。
- **HTTP 401 / 403**：会话可能失效，或接口对该账户不可用。请重新登录并刷新。
- **面板未出现**：确认 Tampermonkey 已启用；普通聊天需要**展开左侧栏**，Work 需要「输出 / 来源」（或 Output / Sources）右上角面板。侧栏折叠或窄屏时不会强行覆盖内容。
- **数据不一致**：脚本周期性读取内部接口，官方用量页面的数据优先。

提交 Issue 时只能提供**脱敏的字段结构**，不要泄露 Token、Cookie、邮箱或账号信息。

## 开发


CI 将检查脚本语法、额度解析测试及 Tampermonkey 更新元数据。发布时同步修改脚本 `@version` 和 package.json 中的版本，推送 `vX.Y.Z` 标签可自动创建 Release。Tampermonkey 从 main 分支获取更新。

## 兼容性说明

脚本优先通过 Work「输出 / 来源」标题及位置识别右上角面板；普通聊天通过展开侧栏的账户按钮（`accounts-profile-button`）挂载额度图标，必要时使用侧栏 footer 备用定位。动态圆弧与弹窗使用相同的真实额度数据；弹窗仅在点击时挂载到页面顶层，避免侧栏裁剪，关闭后立即移除。两种 DOM 结构均非公开稳定接口，OpenAI 改版时可能需要更新。**v1.3.4** 修正了上下额度弧段方向相反的问题；头像定位优先选择真正的彩色头像而非外部圆形容器。对出现头像偏左、文字偏右的侧栏 DOM，新增相对间距校准和回归测试。**实际浏览器布局仍需确认。**

### v1.3.5 侧栏挂载修复

针对额度按钮在 ChatGPT 网页侧栏消失的问题，放宽账户按钮识别条件：支持 `data-testid` 被修改以及账户按钮属性变化，检测时同时确认它位于可见的展开侧栏底部。头像布局对齐现在有独立异常保护，即使前端修改导致头像样式读取失败，也不会阻止额度 UI 挂载和数据请求。新增真正启动 Chromium 的集成测试，覆盖正常侧栏、账户入口属性改变、头像读取异常三个场景。**上述为模拟网页测试，仍非真实登录 ChatGPT 的 DOM 验证。**

### v1.3.6：CSP 兼容与运行状态诊断

脚本改为 Tampermonkey `@sandbox DOM`（移除 `@grant none`），尽量在独立的 DOM 沙箱中执行，而非直接注入受网页 CSP 约束的页面脚本环境。不修改 ChatGPT 的安全策略。

打开 F12 → Console，输入下面的命令查看运行阶段（**不会读取 Token 或账号资料**）：

```js
({
  version: document.documentElement.dataset.cgQuotaMonitor ?? '未启动',
  status: document.documentElement.dataset.cgQuotaState ?? '未知',
  reason: document.documentElement.dataset.cgQuotaReason ?? '',
  mounted: !!document.getElementById('cg-work-quota-root'),
})
```

`未启动`：优先检查扩展、脚本是否启用以及执行权限；`profile-not-found`：脚本已运行，但未识别到可用的左侧栏账户按钮；`sidebar-mounted`：已挂载，若仍看不到则检查位置和样式；`mount-error`：挂载异常，查看 Console 中带 `[ChatGPT Quota Monitor]` 的错误。上述标记仅含脚本版本和状态，不包含凭证。

**注意：** ChatGPT 开发者控制台中的 `runner.html` CSP 错误可能属于页面自身或其他脚本，不能只凭该信息认定额度脚本被阻止。依次检查运行标记可缩小排查范围。
